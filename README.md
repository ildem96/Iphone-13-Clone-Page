# iPhone 13 Pro Clone

Projeto front-end de uma página inspirada na apresentação do iPhone 13 Pro. Este projeto foi desenvolvido para praticar os fundamentos de **HTML**, **CSS** e **JavaScript**.

## Sobre o projeto

A página apresenta:

- Menu de navegação inspirado na Apple;
- Informações e preço do iPhone 13 Pro;
- Botão de compra;
- Seletor de cores do aparelho;
- Troca dinâmica da imagem do produto;
- Layout adaptado para telas menores.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como funciona a troca de cores

Ao clicar em uma das opções de cor, o JavaScript:

1. Remove a seleção da cor anterior;
2. Marca a nova cor como selecionada;
3. Altera o caminho da imagem exibida;
4. Aplica uma pequena transição visual na imagem.

## Objetivo de aprendizado

Este projeto é indicado para iniciantes que querem praticar:

- Estrutura básica de uma página HTML;
- Seletores e estilos com CSS;
- Media queries para responsividade;
- Seleção de elementos com JavaScript;
- Eventos de clique;
- Alteração de atributos e classes no DOM.
